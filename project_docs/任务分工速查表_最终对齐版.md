## 固定命名

- 后端：`backend/app/api/food.py`、`backend/app/api/recipes.py`、`backend/app/api/chat.py`。
- 前端：`frontend/src/api/food.js`、`frontend/src/api/recipe.js`、`frontend/src/api/chat.js`。
- 集成：`integration/day3-mock`、`integration/day4-real`。
- SSE：token、recipe_updated、done、error。

## 一句话规则

读 V1 -> 先运行已有代码 -> 用 Adapter 对齐对外接口 -> 用 canonical fixture 开发 -> 运行契约测试 -> 不一致退回 owner。内部允许创新，对外字段不得私改。

V1.1 只修改 Food 多图上传：公开字段为 `images`，每批 1～5 张、单张不超过 10 MB、整批不超过 50 MB，一批只创建一个 `recognition_id`。Recipe、Chat、SSE 不变。
