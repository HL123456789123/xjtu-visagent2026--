# 统一接线需求模板

> 本文件只提供模板。当前没有记录或虚构任何成员已经提出的接线需求。

## 使用规则

1. 业务 owner 完成可运行模块后，复制下面模板新增一条接线需求。
2. 固定输入、固定输出必须引用 `docs/contracts/api_v1.md` 的对应章节，不得重新设计字段。
3. 共享入口只接受可验证的目标文件、修改原因和测试方法。
4. 没有 PR 或 Commit 时如实填写“暂无”，不得虚构编号。
5. 接线不承担业务代码修复；契约不一致先退回原 owner。
